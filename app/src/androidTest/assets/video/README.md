The original silent white video with Hello MangaLens lettering is generated before CI assembly by `bash .github/scripts/create-video-ocr-fixture.sh`. Run this command before local connected tests too. It uses FFmpeg color/drawtext, DejaVu Sans, H.264 yuv420p, 640×360 at 10 fps for five seconds. No third-party footage or user URLs are included. The test decodes the generated base64 asset into a temporary local file and verifies real Media3 decoding, TextureView frame capture and OCR. The fixture belongs only to androidTest assets, not the application APK.
