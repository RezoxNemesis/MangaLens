# Model governance and bounded evaluation evidence

This adds publisher/license metadata for the existing exact Lite, Core and authenticated historical pins. It does not change Catalog descriptors, local filenames, pin equality, activation journals, rollback, readiness, memory admission or MAX's unavailable state. The Orez Engine panel shows **selected-pack** metadata and pending qualification; it does not label the currently running fallback as the selected pack. Bundled Apache 2.0 and native MIT text is acquired, bounded, hashed and decoded on IO when the user opens Model licenses.

Publisher metadata is a saved collection snapshot from the exact pinned repository revision. The archived API body includes mutable download counters; its SHA identifies the collected snapshot, not an immutable upstream API response or inspected weight bytes. Matching publisher LFS metadata/license text does not constitute tensor inspection, native compatibility, model quality or physical-device evidence. `publisher-provenance.json` records the exact public source URLs and correspondence.

## Evaluation contract

The first contract is a typed, internal bounded text-evaluation validator with canonical binary commitments. It has **no external JSON/report importer, evaluator, training runner, public qualification API or model-activation hook**. A later app-owned IO loader/evaluator must supply actual artifact bytes and independent reviewed registrations; this code does not turn a report's passed/physical/trusted flag into authority.

The scope binds all three model-pin fields; publisher/license identity; native ABI/binary/tensor/source evidence; app version, source, complete build-input digest and APK; task/native input/profile/protocol/rubric; licensed corpus/held-out/source/prompt cases; device kind/capabilities/SDK/RAM/storage; target/style/budget and observed settings. A matching baseGitSHA alone cannot reuse another dirty build's qualification.

Exact expected cases, actual result cases, canonical corpus/held-out manifests, role commitments and supplied bodies must agree. Required scoped bodies include archived publisher metadata/license/runtime license, tensor/device/protocol/rubric/corpus-license/build-input receipts. Required case bodies include source, captured native prompt, one output-or-error, judgment and measurement. Every failed/cancelled case remains in the denominator. Corrupt present evidence is Invalid before missing/unregistered/other-scope/smoke Pending outcomes. Valid hashes of unrelated manifests, omitted failures and extra bodies cannot produce verified evidence.

Accepted inventories are bounded defensive snapshots. Receipt/manifest commitments each have a 256 KiB cap; at most 128 cases/1024 artifact entries; one body at most 1 MiB; committed and supplied volume at most 16 MiB. Artifact/hash/UTF-8 work belongs off Main. This text contract must not be reused for unbounded vision/audio corpora.

Current supported localization input is the immutable `orez-localization-v2` profile with **288 output tokens**, independently of the native service's generic 96..320 clamp. Observed context is prompt tokens + output limit +64; generic native thread/batch/microbatch/sampler constraints are checked. A known V2 contradiction is Invalid even if other bodies are missing or the request is for another scope. Early native faults can explicitly retain NOT_OBSERVED settings without inventing context/sampler/peak measurements. Passing cases require complete actual observed settings and EOG. This first all-cases-completed text protocol cannot positively qualify cancellation competency or unknown hardware measurements.

Historical pack minimum-app information is NotDeclared, preserving old availability. New empirical profiles need their own declared minimum-app/schema/runtime/input tuple; an old pack's unknown field does not disqualify an otherwise eligible new profile. Unsupported profile/task/measurement combinations remain Pending. The default reviewed-result registrations and passing-approval set are empty. A complete registered failed result can be ObservedFailure without passing approval; qualification requires separate exact-digest passing approval. Synthetic test registrations never ship as real approvals.

## Remaining empirical workflow

Real licensed grouped training/held-out dataset production, local training/conversion, actual model/device evaluation, bounded report import/export and reviewed production approval remain separate work. Native model runs, quality/performance evidence, RAM/KV/resource profiles and physical sensors are not provided by the metadata/validator/UI candidate. MAX remains reserved until a separate supported descriptor/profile and truthful empirical qualification are established. Existing local chat remains usable under its current safety/resource rules.
